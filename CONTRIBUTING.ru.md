# Участие в разработке Turbo Quant Memory

[English](CONTRIBUTING.md) · [Українська](CONTRIBUTING.uk.md)

Нужны Python 3.11+ и uv. После клонирования репозитория выполните проверки из [CI](.github/workflows/ci.yml):

```bash
uv sync --frozen
uv run --no-sync ruff check src tests
uv run --no-sync mypy src/turbo_memory_mcp
uv run --no-sync pytest -q
```

При установке зависимостей и моделей эмбеддингов может потребоваться сеть. Для тестов используйте временные данные, а не единственную копию рабочего хранилища памяти.

В отчёте об ошибке укажите версию пакета, ОС, Python, MCP-клиент, минимальные шаги воспроизведения и очищенные диагностические данные. Не публикуйте секреты, приватные заметки, локальные базы или учётные данные.

Делайте изменения небольшими и добавляйте регрессионные тесты для новой логики. Сохраняйте совместимость миграций и границу между проектной и глобальной памятью. Перед изменением контрактов инструментов или установки прочитайте [AGENTS.md](AGENTS.md) и [инструкцию агента](src/turbo_memory_mcp/skills/turbo-quant-memory/SKILL.md).

Синхронизируйте пользовательскую документацию на английском, украинском и русском. README.md также используется на PyPI: ссылки на файлы и изображения в нём должны быть абсолютными. Не редактируйте вручную сгенерированный блок TQ-STATS и не выдавайте его исторический пример за текущий бенчмарк.

В pull request опишите проблему, изменения, выполненные команды и фактические результаты, включая пропущенные или заблокированные проверки. Различайте локальное хранилище сервера и передачу данных MCP-клиентом. [Лицензия MIT](LICENSE) не меняется.
